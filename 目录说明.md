# 项目目录说明

```
prismPanel/  棱镜面板
├── frontend/                 # 前端项目
│                              #   当前为守护进程联调用零构建静态页面
│                              #   正式前端重写后由 Web 浏览器和 Windows App 复用
│
├── winapp/                   # Windows 桌面应用（Wails 框架）
│                              #   薄壳层，复用 frontend/ 的全部 UI 代码
│                              #   仅包含 Go 编写的系统调用层
│
├── panel/                    # 面板后端服务（go）
│                              #   提供 REST API 和 WebSocket 接口
│                              #   负责用户管理、镜像管理、插件中心等核心业务
│                              #   通过原生 WebSocket 与各节点守护进程通信
│
├── daemon/                   # 守护进程（go）
│                              #   部署于每台运行 MC 子服的 Linux 节点
│                              #   负责子服启停、性能采集、控制台转发、文件管理
│                              #   编译为单一二进制文件，零依赖分发
│
├── prism-plugin/             # spigot对应插件（Java）
│                              #   用来向守护进程注册本服插件/版本/端口
│                              #   还可以管理本服配置文件
│
├── docs/                     # 项目文档
│                              #   协议、数据模型、架构设计和运行说明
│
├── reference/                # 参考项目
│                              #   参考这里面的项目，可以参考思路和实现方案
│
├── .github/                  # GitHub Actions CI/CD 配置
│                              #   各模块独立构建、自动发布
│
├── .gitignore                # Git 忽略规则
├── LICENSE                   # 开源许可证
└── README.md                 # 项目说明
```
