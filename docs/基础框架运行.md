# 守护进程基础框架运行说明

## 目录

```text
daemon/
├── cmd/prism-daemon/         守护进程入口
└── internal/
    ├── api/                  HTTP、管理 WebSocket、控制台 WebSocket
    ├── config/               YAML 全局配置
    ├── server/               服务器配置服务
    ├── store/                逐服务器 JSON 存储
    ├── supervisor/           服务器进程和控制台管理
    └── ticket/               浏览器直连临时凭证

panel/
├── cmd/prism-panel/          测试面板入口
└── internal/
    ├── api/                  测试 REST API 和控制台 WS 代理
    ├── audit/                JSONL 操作审计
    └── daemon/               daemon 管理 WS 客户端

frontend/                     零构建依赖的临时联调页面
```

## 启动

首次启动 daemon 会生成 `data/daemon.yaml` 和 `data/secret.json`：

```powershell
cd daemon
go run ./cmd/prism-daemon
```

启动测试 panel。默认配置会读取同一工作区下 daemon 生成的密钥，并托管 `frontend/`：

```powershell
cd panel
go run ./cmd/prism-panel
```

浏览器访问 `http://127.0.0.1:8080`。创建普通或镜像实例时，直接填写完整启动命令和写入 stdin 的停止命令，不需要修改 daemon YAML。

普通实例启动命令示例：

```text
java -Xms1G -Xmx2G -jar paper.jar nogui
```

Windows 也可以填写带空格的完整路径：

```text
"C:\Program Files\Java\jdk-25\bin\java.exe" -Xms1G -Xmx2G -jar paper.jar nogui
```

启动命令在实例工作目录中执行。Windows 使用 `cmd.exe`，Linux 使用 `/bin/sh`；配置启动命令等价于授予 daemon 运行账户的 Shell 执行权限，只应交给受信任管理员。

测试页面的镜像创建器会根据实例数量动态生成端口输入，并支持逐项配置文件/文件夹排除规则。创建后派生实例 ID 和目录仍遵循 `<server_id>_<slot>` 规则。

生产环境中 panel 和 daemon 不在同一主机时，编辑 `panel/data/panel.yaml`：

```yaml
daemon:
  url: http://192.168.1.20:24444
  secret: <daemon 主密钥>
  secret_file: ""
```

也可以通过 `PRISM_DAEMON_SECRET` 环境变量提供密钥，环境变量优先于 YAML。

## 密钥管理

```powershell
cd daemon
go run ./cmd/prism-daemon -show-secret
go run ./cmd/prism-daemon -reset-secret
```

重置密钥后，现有 panel 管理连接会在断线后无法重新认证，需要同步更新 panel 配置。

## 当前管理接口

| 方法 | 路径 | 作用 |
|---|---|---|
| `GET` | `/api/v1/health` | panel 与 daemon 连接状态 |
| `GET/POST` | `/api/v1/servers` | 查询或创建服务器 |
| `GET/PUT/DELETE` | `/api/v1/servers/{server_id}` | 查询、保存或删除配置 |
| `POST` | `/api/v1/instances/{instance_id}/start` | 启动实例 |
| `POST` | `/api/v1/instances/{instance_id}/stop` | 正常停止，超时后强杀 |
| `POST` | `/api/v1/instances/{instance_id}/restart` | 顺序停止并启动 |
| `POST` | `/api/v1/instances/{instance_id}/kill` | 强杀实例进程树 |
| `POST` | `/api/v1/instances/{instance_id}/command` | 审计并转发控制台命令 |
| `POST` | `/api/v1/instances/{instance_id}/console-ticket` | 签发只读日志凭证 |
| `WS` | `/api/v1/ws/console` | `public_url` 为空时代理控制台日志 |
| `POST` | `/api/v1/servers/{server_id}/deploy` | 部署当前指定槽位或全部镜像实例 |
| `GET` | `/api/v1/deployments/{task_id}` | 查询部署状态和有界日志 |
| `POST` | `/api/v1/deployments/{task_id}/cancel` | 在安全点取消部署 |
| `POST` | `/api/v1/deployments/{task_id}/force-stop` | 强制结束部署且不恢复运行状态 |

panel 测试 API 当前不包含用户系统，调用者记为 `test-user`，也可通过 `X-Prism-Actor` 指定联调用户名。所有改变状态的操作写入 `panel/data/audit.jsonl`。
