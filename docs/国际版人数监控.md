# PrismPanel 国际版人数监控（服主/管理员指南）

> **Minecraft Java 版服务器在线人数监控**：手动登记服务器 IP[:端口]，面板服务端自动定时采集并记录历史趋势。

## 一、功能概览

- **手动输入服务器 IP[:端口]**（默认端口 25565，支持 IPv6 方括号字面量）
- **服务端自动记录**：独立采集循环按可配置间隔 ping 所有启用的服务器，在线人数/最大人数/延迟/版本写入数据库，历史可查询、可绘图
- **三协议回退**：现代 Server List Ping（1.7+）→ legacy 0xFE（1.6/1.3 风格）→ 0xFA MC|PingHost（1.4/1.5），纯标准库实现，无第三方依赖
- **页面入口**：「服务器监控」页即本功能，独立页面，仅国际版服务器监控

## 二、前端操作

入口：登录面板 →「服务器监控」页。

| 操作 | 说明 |
|---|---|
| 添加服务器 | 填写名称 + 服务器地址 `IP[:端口]` + 备注 + 启用开关（需超级管理员） |
| 编辑/删除 | 修改名称/地址/备注/启用状态（需超级管理员） |
| 立即采集 | 点「立即采集」手动触发一轮（需超级管理员） |
| 查看趋势 | 单服行内趋势图（复用 MCServerSeriesChart 折线图组件），支持时间范围选择 |
| 状态列 | 状态标签（在线/离线）、在线/最大人数、延迟 ms、版本、最后更新时间 |

设置对话框可配置**国际版采集间隔**（分钟，1-60，默认 1；修改后**立即热生效**，无需重启面板）。

## 三、API

> 写操作（增删改/立即采集）要求**超级管理员**；读操作要求 `dashboard.view`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/net-games/mc-servers` | 服务器列表 + 最新采集结果 |
| POST | `/api/v1/net-games/mc-servers` | 添加服务器（超管） |
| GET | `/api/v1/net-games/mc-servers/{id}` | 单服详情 |
| PUT | `/api/v1/net-games/mc-servers/{id}` | 更新（超管） |
| DELETE | `/api/v1/net-games/mc-servers/{id}` | 删除（超管，观察点级联删除） |
| GET | `/api/v1/net-games/mc-servers/series?servers=key1,key2&hours=N` | 多服趋势数据（`game_id=host:port` 规范化键） |
| POST | `/api/v1/net-games/mc-servers/collect` | 立即采集一轮（超管） |

series 返回结构：`{game_id, name, points: [{sampled_at, value, max_players, latency_ms, version_name}]}`，前端折线图组件直接消费。

## 四、数据模型

- `mc_servers`：id、name、`game_id`（规范化 host:port，唯一键）、host、port、enabled、note、`last_status/online/max/latency_ms/version/error/checked_at`、时间戳
- `mc_server_observations`：server_id（外键，级联删除）、sampled_at、online、max_players、latency_ms、version_name、protocol
- MySQL 与 SQLite 双实现同步（`store_sqlite.go` 自动翻译）
- 历史按 `history_retention_days` 定时清理

## 五、采集行为

- 每轮采集并发 8 个 worker，单服务器 5s 超时；单轮上限 10 分钟
- 成功：写观察点 + 更新 `last_*`；失败：只更新 `last_status`/`error`（不写观察点，折线无断点填充）
- 创建/更新服务器后异步立即 ping 一次
- 并发防重入（`ErrMCCollectorBusy`）

## 六、安全说明

- **SSRF 缓解**：只有超级管理员能登记采集目标；采集目标全部来自数据库已登记服务器（无通过查询参数 ping 任意地址的入口）；5s 超时 + 并发上限
- 可选强化（未启用）：默认拒绝私有/回环地址（127.0.0.1、169.254.x、10.x 等）+ 显式开关，如需可加
- 读接口 `dashboard.view` 用户可见服务器 host/port（与面板其它监控读接口同权限策略）

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 服务器一直"离线" | 检查地址可达性、端口是否开放（协议为 Server List Ping，非 TCP 连通即可）、面板出网能力 |
| 地址解析 | 支持 `mc.example.com`、`192.168.1.10:25570`、`[2001:db8::1]:25565`；不带端口默认 25565 |
| 延迟为 0 或缺失 | 部分服务端不支持 ping/pong 测延迟，仅返回在线/最大人数 |
| 修改间隔不生效 | 新版已支持热生效；若面板版本较早需重启面板 |
