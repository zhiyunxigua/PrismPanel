# PrismPanel 改造总览（2026-08）

> 本文汇总 PrismPanel 在 2026-08 完成的三大改造与后续待办落地，作为文档入口。
> 配套文档：[mod 统一管理与配置同步](./mod统一管理与配置同步.md) · [国际版人数监控](./国际版人数监控.md) · [WinApp 启动器改进](./WinApp启动器改进.md) · [PCL2 源码研究报告](./PCL2-winapp改进建议.md) · [审查报告](./审查报告-2026.md) · [mod 运行态上报设计](./mod运行态上报设计.md)

---

## 一、改造目标

1. **服务器端拓展 mod 支持**：镜像服务器组的配置同步从仅 `plugins/` 扩展为多目录同步根（含 mod 服 `config/`）；像管理 Bukkit 插件一样统一管理 Fabric/Forge 模组（扫描/启停/部署/漂移检测）；并实现 mod **运行态**上报（服务端实际加载了哪些 mod）。
2. **人数监控（国际版）**：新增 Minecraft Java 版服务器在线人数监控——管理员手动输入服务器 IP[:端口]，面板服务端自动定时采集并记录历史。
3. **WinApp 客户端参照 PCL2 改进**：对照 `EG/Plain Craft Launcher 2`（PCL2 官方 VB.NET 源码）改进国际版启动器的下载、启动参数、Fabric 安装、Java 选择与 Mod 管理。

## 二、改造一：服务器端 mod 支持

### 2.1 mod 平台支持（daemon/panel 共用枚举）

合法平台扩为 `paper / spigot / fabric / forge / velocity / bungee`，集中定义于 `daemon/internal/model/server.go`：

| 函数 | 语义 |
|---|---|
| `IsSupportedPlatform` | 合法平台唯一判定点（Validate 引用） |
| `IsModPlatform` | fabric/forge |
| `IsProxyPlatform` | velocity/bungee |
| `ModTypeForPlatform` | fabric/forge → 自身，否则 "" |
| `PluginTypeForPlatform` | proxy→自身、mod→自身、其余→"spigot" |
| `ArtifactDirectory` | mod 平台 → `mods`，其余 → `plugins` |
| `IsModArtifact` | fabric/forge → true |

### 2.2 mod config 统一同步（多目录同步根）

- 新增配置字段 `config_sync_directories`（仅镜像组使用）：
  - 默认值：paper/spigot → `["plugins"]`（旧配置向后兼容）；fabric/forge → `["config","plugins"]`
  - 每个目录经 `validateRelativePath` 校验（拒绝绝对路径与 `..` 逃逸），支持嵌套（如 `mods/config`）
- daemon `deployment/plugin_config_sync.go` 重构为 `syncConfigFiles`：遍历所有同步根，每根独立扫描/复制/进度（stage `scanning_config`/`copying_config`）；`plugins` 根保留"跳过根级 jar"语义，`config` 等根允许根级白名单散文件；仍拒绝符号链接、临时文件原子发布
- 后缀白名单 `plugin_config_sync_extensions`（默认 .yml/.yaml/.json/.toml/.ini/.conf/.properties/.xml）不变，多根共用
- 前端：服务器编辑对话框平台下拉新增 Fabric/Forge，"配置同步目录"多选（切平台自动更新默认值）；详情页按钮改"同步配置"+tooltip 显示目录清单

### 2.3 mod 统一管理（mods 目录）

- **描述符解析**：`fabric.mod.json`（jar 根 JSON）+ `META-INF/mods.toml`（极简 TOML + 文件名回退）；auto 探测顺序插件在前 mod 在后
- **命令**（daemon 管理 WebSocket，与 plugin.* 并存）：
  - `mods.list` / `mods.enable` / `mods.disable` / `mods.uninstall`
- **启停**：`.jar ↔ .jar.disabled` 重命名（Fabric/Forge 加载器约定），目标已存在时拒绝
- **漂移检测**：启动前基线哈希（按 `ArtifactDirectory`）+ 运行中扫描，`file_changed_since_start` / `version_mismatch` / `disabled_pending_restart` 等状态
- **panel 插件仓库**：支持 fabric/forge 类型发布（`ValidPluginType` 含 fabric/forge），`/api/v1/plugins/{type}/{plugin}/{artifact}/deploy` 按平台过滤部署目标（fabric 制品不会装进 spigot 服）；`BuildBundle` 按类型路由；上传/部署/启用/禁用/回滚全套沿用插件体系
- 前端 `PluginsView.vue` 平台筛选显示"Fabric 模组"/"Forge 模组"

### 2.4 mod 运行态上报（Fabric）

> 详细设计见 [mod运行态上报设计.md](./mod运行态上报设计.md)；实现为最小闭环。

- **上报载体**：新建 `prism-plugin/fabric/` 子模块（`:fabric`），复用 `:core` 的 `DaemonBridge/PrismCore`；`FabricLoader.getAllMods()` 只采集 `ModOrigin.Kind.PATH`（fabric-loader 0.16.x 枚举为 PATH/NESTED/UNKNOWN），过滤内置 id（minecraft/fabricloader/java）与自身（prism-fabric）
- **协议**：零新增消息——复用 `/api/v1/ws/plugin` + `snapshot`，mod 列表放 `plugins` 数组（实例平台 fabric 即语义分界）；新增 `mod.inventory` capability；10s 心跳 / 5s snapshot / 实例重启代次失效全部复用
- **daemon 改动**：
  - `LoadedPlugin` 新增可选 `id`；`PluginReport.OnlinePlayers/MaxPlayers` 改 `*int`（Fabric 无 MC 类取不到玩家数，避免假 0/0）
  - `merge()` 匹配顺序 `byFile → byID → byName`；`mods.list` 过滤 prism-fabric 自身并重算 pending
- **构建与部署**：产物 `prism-fabric-0.2.0.jar`（357KB，无 Loom、只依赖 fabric-loader API、gson 已 relocate），放入 Fabric 子服 `mods/`，daemon 注入 `PRISM_*` 环境变量后自动连接上报
- **Forge**：评估后延后（版本碎片化严重），协议已按加载器无关设计

## 三、改造二：人数监控接入国际版

- **采集器** `panel/internal/netgames/mc_ping.go`（纯标准库）：现代协议（handshake+status+ping/pong 测延迟）→ 回退 legacy 0xFE → 再回退 0xFA MC|PingHost；5s 超时、响应上限 1MiB、VarInt 边界校验
- **手动登记**：`host[:port]`（默认 25565、IPv6 方括号），规范化唯一键 `game_id=host:port`；名称/备注/启用开关
- **服务端自动记录**：独立采集循环（间隔 `mc_collection_interval_minutes`，默认 1 分钟、范围 1-60，**运行中修改热生效**——每 tick 重读设置重建 ticker）、8 并发 worker、成功写观察点+更新 last_*、失败记状态；历史按 `history_retention_days` 清理
- **API**：
  - `GET/POST /api/v1/net-games/mc-servers`（写操作需超管）
  - `GET/PUT/DELETE /api/v1/net-games/mc-servers/{id}`（写操作需超管）
  - `GET /api/v1/net-games/mc-servers/series?servers=key1,key2&hours=N`
  - `POST /api/v1/net-games/mc-servers/collect`（需超管，立即采集）
- **存储**：`mc_servers` + `mc_server_observations`（级联删除），MySQL/SQLite 双实现同步
- **前端**：`NetGamesView.vue` 单页「服务器监控」（原双标签页面已合并为单页），含添加/编辑对话框、状态表（在线/最大/延迟/版本）、单服趋势图（复用 MCServerSeriesChart）、立即采集按钮
- **安全**：创建/更新/删除/立即采集要求超级管理员；仅登记目标可被采集（无任意地址 ping 入口）；5s 超时 + 并发上限

## 四、改造三：WinApp 客户端参照 PCL2 改进

> 完整研究报告见 [PCL2-winapp改进建议.md](./PCL2-winapp改进建议.md)（353 行，29 条速览表）；改进清单见 [WinApp启动器改进.md](./WinApp启动器改进.md)。

对照 PCL2 源码（`EG/Plain Craft Launcher 2/Modules/Minecraft/` 等）实施 **24 条低风险项 + 4 项跟进 + 后续 P2 三项中风险**，全部在 `winapp/internal/game/`：

- **下载**：sha1/size 校验（损坏自动重下）、429 退避 + BMCLAPI 节流、大文件 30min 长超时、取消不拉黑源、测速 10min TTL、候选源按域名分流
- **启动**：参数去重（移植 PCL2 `DeduplicateJavaArguments`）、QuickPlay 自动进服（23w31a 精确边界）、打码启动命令日志、启动前补全检查、JVM 占位符 dropUnresolved 兜底、natives 启动前按"文件名+大小"完整核对 + 清版本残留、中文用户名按 Java 大版本注入编码参数（UTF-16 原生传递）
- **Fabric**：库并发下载、空 URL maven 兜底、判装校验 json、profile JSON 单次请求
- **Java**：运行时并发下载、官启 runtime 目录扫描、下载后大版本校验、组件映射经 Mojang 官方数据三方实证（alpha=16、beta/gamma=17、delta=21、epsilon=25）+ 22+→epsilon 前瞻分支
- **Mod**：Modrinth 覆盖安装 Bug 修复 + size 校验、**依赖自动安装**（递归 required、去重防环、深度上限 5）

## 五、网易版 MC 移除（2026）

项目已**全量移除网易版 Minecraft 相关功能**（panel 网易 X19 客户端/采集/账号/表/路由、winapp 网易启动/账号/运行时、frontend 网易页面与方法），国际版（Minecraft Java 版）功能完整保留。移除后的备份文件位于 `PFW-common/.removed-netease-panel/`、`.removed-netease-winapp/`、`archived-docs-removed/`（确认后可删除）。

> 发布提醒：`frontend/dist`、`winapp/assets`（go:embed）、`build/*`、根目录 `PrismPanel.exe` 若为移除前的旧预构建产物，仍含网易代码，发布前必须在有权环境重建（见第七节）。

## 六、WinApp 下载链路故障修复（2026）

用户实测中逐层暴露并修复了 4 个下载/启动问题（`winapp/internal/game/`，均有对应测试）：

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 资源文件全部下载失败（5057 个，404） | `downloadMCAssets` 把资源索引的 **map key（资源路径）当 sha1 hash** 构造 URL/磁盘路径，全部 404 | 改用 `obj.Hash`（+集成测试 `TestDownloadMCAssetsUsesHashNotKey`） |
| 2 | libraries 403（误下载 arm64 natives） | MC 26.2 版本 JSON 把 natives 展开为独立条目，规则仅按 os 匹配；旧逻辑**下载了所有平台变体** | 新增 `mcNativesVariantAllowed` 按平台+架构过滤（+`TestMCNativesVariantAllowed`） |
| 3 | Fabric 库 404（`/maven/` 路径丢失） | Fabric profile 的库 URL 为 **maven 基地址**（无 jar 路径），原样返回导致路径丢失 | `fabricLibraryURL` 基地址按坐标补全（+`TestFabricLibraryURLBaseAddress`） |
| 4 | 启动后进入**试玩模式** | MC 26.2 `arguments.game` 自带 `--demo`（规则 `features.is_demo_user=true`），规则求值忽略 features 误传 `--demo` | 规则求值支持 `features.is_demo_user` + 防御性剔除 `--demo`（+`TestMcRulesAllowDemoFeature`/`TestBuildMCLaunchArgsDropsDemo`） |

辅助改进：健康记忆候选全被过滤时回退原始候选（防级联全灭）、失败信息携带首个真实错误、下载请求补 User-Agent、单次尝试 10s 限时 + 提前终止（防假死）。

## 七、发布打包指引（需有权环境）

沙箱内 `npm run build` 因 esbuild EPERM 无法执行（提权亦被拒），**必须在普通/有权环境**执行：

```bat
cd C:\Users\13602\Desktop\PFW-common\PrismPanel-master
:: 一键全量构建（前端 → daemon/panel/winapp，产物到 build\）
build-all.bat windows          :: 或 build-all.bat（三平台）

:: 或仅重建 WinApp（含重新嵌入前端 assets）
cd winapp
build.bat ..\build\windows-amd64\winapp\PrismPanel.exe
```

流程核对：`build-all.bat` → `frontend npm run build`（产出无网易 dist）→ 平台 Go 构建 → `winapp/build.bat`（`build-frontend.ps1` 将新 dist 拷入 `winapp/assets` 后 go:embed 打包）。**切勿把旧 `winapp/assets` 打进发布包**。
