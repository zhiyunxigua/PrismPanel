### 4.2 安全性审查（SSRF / 路径注入 / 输入校验）

- **地址校验**：`NormalizeMinecraftAddress`（mc_ping.go:61-101）支持 host、host:port、IPv6 方括号字面量；端口 1-65535 强校验（`:103-109`）；host 规范化（去空白/小写/去尾点）。**无路径注入面**：host 只用于 `net.JoinHostPort` 做 TCP 连接，不参与任何文件系统路径。
- **SSRF 评估**：面板服务端会对管理员录入的任意 `host:port` 发起 TCP 连接。缓解因素：
  1. 创建/更新/删除/立即采集全部要求**超级管理员**（`api/mc_servers_handlers.go:35/76/93`、server.go:121 路由级 requireSuperAdmin），普通面板用户无法新增 ping 目标；
  2. 采集目标全部来自数据库已登记服务器，无"通过查询参数直接 ping 任意地址"的入口（series 仅查历史数据）；
  3. 有 5s 超时与并发上限，不会被单点拖垮。
  结论：在"仅超管可登记目标"的权限模型下，SSRF 风险可控、可接受。**建议（可选强化）**：如需防超管误录内网/回环地址（如 127.0.0.1、169.254.x、10.x 等），可加"默认拒绝私有地址 + 显式开关"的校验层；当前非阻塞。
- **观察点清理**：`mcPurgeOldHistory` 按保留天数清理，无注入。
- **并发安全**：`mcCollectAll` 用 mutex 防重入（`ErrMCCollectorBusy`），8 worker 池，单次 10 分钟上限。

### 2.2 脱敏（maskSensitive）—— 不得记录密码/accessToken ✅

三级规则（mc_dev.go:208-228）：

1. JSON 键值：`"access_token"|"refresh_token"|"client_token"|"clientsecret"|"password"|"passwd"|"secret"|"authorization"|"apikey"|"api_key"|"token": "..."` → `"$1":"***"`（`(?i)` 大小写不敏感）；
2. 键值对：同键清单 + `= 或 :` → `***`（覆盖 `password=mysecret`、URL 查询 `?access_token=TOK` 等）；
3. 兜底：**长度 ≥ 48 的连续 token 状字符串**（`[A-Za-z0-9_\-.]{48,}`）→ `***`（覆盖无键名 JWT/accessToken 长令牌）。

应用面：`Detail`、`Input`、`Error`、`ErrorDetail` **四处全部过 `maskSensitive`**；写入 dev-mode.log 的 `line` 全部由脱敏后字段拼装。启动链路（`MCLaunch` 的 Input 含 `jvm=` JVM 参数）与登录链路（auth-status 的 Input 只含 mode/name，不含 token）均无 token 直写面；`maskLaunchArgs`（启动参数打码）为既有独立防线，本轮未改。

测试覆盖：`TestDevLogMasksSensitiveDetail`（password/access_token/token 键值）、`TestDevLogMasksLongToken`（96 字符无键名 token）、`TestMaskSensitive`（10 用例矩阵：JSON/键值/长 token/URL 查询/短字符串不动）、`TestDevLogEntryFillsNewFields`（新字段全断言）、`TestDevLogKeepsOldFields`（向后兼容）、`TestDevLogRingLimit`（500 环形）、`TestDevLogWritesFile`（文件含 app=/GOOS/GOARCH）、`TestDevLogDisabledWhenDevModeOff` —— 全部通过。

## 中文路径 header 修复审查（t1 实现，跨端）

### 结论：✅ 通过（0 阻塞 / 0 P1；3 项 P3 观察；审查未改任何功能代码）

**问题背景**：前端 `fileHeaders` 把 UTF-8 路径直接放入 `X-Prism-Path` HTTP header，浏览器 `Headers` 构造只允许 ISO-8859-1 字节，中文路径抛 `Failed to construct 'Headers': String contains non ISO-8859-1 code point`；panel 代理复制该 header 时 Go `Header.Set` 同样拒绝非 Latin-1。修复方案为「路径改走 URL query（百分号编码），header 仅作旧客户端回退」。

### 1. 前端 fileApi.js（改动 5 行）
